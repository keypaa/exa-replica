# M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap the `exa-replica` repo skeleton with the D95 layout, D96 import contracts, CI, DCO, and versioned contract stubs (OpenAPI + `tools/list`), so every later milestone builds on an enforced architecture.

**Architecture:** `src/<pkg>/` split into `domain/` (pure), `ports/` (D85 interfaces), `application/` (SearchService, TierPlan, orchestrator D86), `adapters/inbound/` (http FastAPI, mcp), `adapters/outbound/` (store, encoder, ann, contents), `bootstrap/` (composition root D92), `entrypoints/` (one per pool D89). Optional Rust crate `ann-core` (R1 only, D82). One Python distribution + optional crate (D95).

**Tech Stack:** Python 3.12, FastAPI/Starlette, `mcp` (Python) 2.x, import-linter, mypy (strict), ruff, pytest, maturin, uv.

**Spec:** `docs/EXA_REPLICA_RESEARCH.md` (D0–D103), `docs/s2_contract_matrix.md`, `docs/s4_manifest_schemas_v0.md`.

## Global Constraints

- No product code before planning is complete (D47) — this plan is the first code.
- Thinkpad never builds (D39); M0 is scaffolding (no GPU) but `cargo`/heavy steps run on the RTX box.
- Python 3.12; `mypy --strict` on `src/<pkg>/`; ruff; import-linter blocking (D96/D102).
- Licenses: code Apache-2.0; models Apache/MIT (D55/D57); MCP SDK MIT (verified).
- Target MCP spec = "Current" at M0 freeze (2026-07-28), SDK `mcp` 2.x (D89 amended).
- Coverage ≥80% lines on `domain/` + `application/`; `adapters/` excluded (contract tests) (D102).
- Conventional commits; PR ≤400 lines (D102); DCO `Signed-off-by` (D98).

## Review Focus

- **`CLAUDE.md` drift:** must contain only the pointer to `AGENTS.md`; CI fails otherwise (D101). Test: `test_claude_md_is_pointer`.
- **Import violations:** `domain` importing fastapi/httpx/`ann_core` must fail CI (D96). Test: `test_domain_has_no_external_imports`.
- **Missing contract snapshot:** a changed OpenAPI/`tools/list` without a snapshot update must fail CI (D103). Test: `test_contract_snapshots_match`.
- **Invalid config at startup:** process must refuse to start on invalid settings (D92/D102). Test: `test_invalid_config_refuses_start`.
- **Wrong MCP target version:** serving a non-current spec revision must be caught at M0 pin (D89). Test: `test_mcp_target_version_pinned`.
