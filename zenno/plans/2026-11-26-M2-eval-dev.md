**Goal:** Build the evaluation harness, the dev golden set, the judge calibration, the dev pilot (σ), the D93 growth decision, and the provisional D81 model choice — with **no test-split execution**.

**Architecture:** Offline eval harness (§1.5/D35) over the M1 pipeline; golden set (D93) with EN gate + FR diagnostic; paired bootstrap; provisional model selection (D81).

**Tech Stack:** Python 3.12, pytest, numpy/scipy (bootstrap), HF datasets (golden set), the M1 pipeline.

**Spec:** `docs/EXA_REPLICA_RESEARCH.md` (D13/D14/D19/D33/D71/D81/D93/D94), `docs/s4_b_thresholds.md`.

## Global Constraints

- Dev split only; test split touched once per RC (D14) — M2 must not run test.
- EN primary gate; FR diagnostic (D93); specific objectives primary (D33).
- Provisional model labelled; cannot enter frozen spec (D81).
- No code changes to product; harness only (D35).

- **Dev/test leakage:** test split must be unread in M2 (D14). Test: `test_test_split_untouched`.
- **σ on raw scores vs paired diffs:** use paired diffs for the BM25 floor (D93/D14). Test: `test_pilot_uses_paired_diffs`.

- **Unjudged top-10:** ≤15% unjudged else complete judging (D81). Test: `test_unjudged_cap`.
